# Visual direction: Signal studio

This project uses its own palette, illustration and editorial hierarchy. The motif follows the project subject: `sound`. The cover is a scalable vector with a 3840 × 1440 display size and a 1920 × 720 coordinate system. It has no external fonts, scripts or image dependencies.

| Token | Value |
| :-- | :-- |
| Background | `#181810` |
| Text | `#f2e9c9` |
| Accent | `#e9c750` |
| Layout | hardware |
| Text contrast | 14.68:1 |
| Accent contrast | 10.83:1 |

The illustration is conceptual. It is not a measured output or an exact wiring diagram. Original photographs, CAD views and screenshots remain separate evidence. Retain their original resolution; do not enlarge a small image and call it high resolution.

GitHub controls the surrounding page style. This theme uses supported Markdown, vector assets and native details sections. It does not depend on custom page CSS.
